# Pre-delivery checklist

Go through this before sending the files. Fix, or state clearly in the chat what is still open.

## Route and transport
- [ ] Every transfer day computed end-to-end; each leg's departure is after the previous activity ends
- [ ] Last departures and ticket-sale dates checked for the hard end (flight/train out) with buffer (domestic flight: at the airport ≥ 1.5–2 h before)
- [ ] Each night's hotel = where that day ends; next day starts there
- [ ] Distances/times come from a map tool, not guessed; labeled as driving or walking
- [ ] Anything bought in a mini-program / on-site is marked "confirm before"
- [ ] Every leg names the exact train no. / departure time, stop, price, where to buy, and 1–2 backup departures
- [ ] Train/bus times checked in both directions (outbound AND return)
- [ ] Local cars: distance, minutes, per-person price, whether ride-hailing works, who to call

## Days
- [ ] Pace matches what the user asked (early starts limited, rest after long transit)
- [ ] Every sight and every meal has a named backup
- [ ] Each stop has a reason (what to see, why it's worth it)
- [ ] Weekdays match dates on the real calendar
- [ ] User's own draft content preserved; additions marked

## Hotels
- [ ] Live prices for the exact dates and party size, with date of lookup
- [ ] Hygiene score + recent reviews checked; bug/noise complaints surfaced
- [ ] Reachability without a car measured (if not self-driving)
- [ ] Platforms that couldn't be checked are named, with the reason

## Output
- [ ] Paged images rendered (one per day / section, each with title + page number) and a few inspected (no overflow, no clipped text)
- [ ] PDF prints with backgrounds; long days break across pages cleanly
- [ ] File names say what and which version; superseded files renamed `旧版_…`
- [ ] Sources listed; unverified items labeled
