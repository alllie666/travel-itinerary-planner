# Pre-delivery checklist

Apply only the checks relevant to the selected transport, research scope and output. Fix, or state clearly what remains open.

## Route and transport
- [ ] Every transfer day computed end-to-end; each leg's departure is after the previous activity ends
- [ ] Last departures and ticket-sale dates checked for the hard end (flight/train out) with buffer (domestic flight: at the airport ≥ 1.5–2 h before)
- [ ] Each night's hotel = where that day ends; next day starts there
- [ ] Distances/times come from a map tool, not guessed; labeled as driving or walking
- [ ] Anything bought in a mini-program / on-site is marked "confirm before"
- [ ] Scheduled legs name the exact train no. / departure time, stop, price, where to buy, and available backup departures
- [ ] Train/bus times checked in both directions (outbound AND return)
- [ ] Local cars: distance, minutes, per-person price, whether ride-hailing works, who to call
- [ ] Self-drive: mapped daily km/time, driving limits, exact scenic/access POIs, detour costs and ranked cuts
- [ ] Mixed trips include pickup/return and station/airport transfer time
- [ ] EV/hiking constraints handled when present; uncertain duration remains a window

## Days
- [ ] Pace matches the user, including driving limits; relaxed pacing applied only when requested
- [ ] Bookable/planned sights and researched meals have named backups; flexible roadside stops have skip/return decisions
- [ ] Each stop has a reason (what to see, why it's worth it)
- [ ] Weekdays match dates on the real calendar
- [ ] Formatting-only drafts preserved; route revisions have explicit change summaries

## Hotels
- [ ] Live prices for the exact dates and party size, with date of lookup
- [ ] Hygiene score + recent reviews checked; bug/noise complaints surfaced
- [ ] Reachability without a car measured (if not self-driving)
- [ ] Platforms that couldn't be checked are named, with the reason

## Output
- [ ] Requested formats delivered; unsupported outputs reported individually
- [ ] Paged images, if selected, rendered in order with title/page number and inspected
- [ ] PDF prints with backgrounds; long days break across pages cleanly
- [ ] File names say what and which version; user-owned old files preserved
- [ ] Sources listed; unverified items labeled
- [ ] HTML/image/PDF contain no leftover template facts or private case data
- [ ] Feishu, if selected: actual URL/revision and changed content read back
- [ ] Amap, if selected: saved days/POIs, km/time, rendered lines and identical cross-day endpoint/startpoint checked
- [ ] All selected outputs share one route version
